#Course Roster Console App
#Bibi Rabbia

This is a simple Course Roster Console App made in Dart.
Completed Parts

Part 1 — Setup & Welcome

I created the main() function and a printWelcome() helper function to display the welcome message.

Part 2 — Course & Roster Data

I used const, final, and normal variables. I also used a List, Set, and Map for course and student data.

Part 3 — Null-Safe Instructor Info

I practiced null safety using nullable variables, ??, and late. I also created a function to generate the enrollment code.

Part 4 — Formatting Strings

I used split() and trim() to clean the student names. I also practiced multi-line strings and string interpolation.

Part 5 — Operators in Action

I practiced ~/, %, is, is!, cascade .., null-safe cascade ?.., and ??=.

Part 6 — Enrollment Logic

I used if/else, switch, and the ternary operator for enrollment status.

Part 7 — Reports & Loops

I used for-in and forEach loops to display the roster and attendance. I also used if and for inside a collection.
