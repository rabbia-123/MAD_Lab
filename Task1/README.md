## Reflection (Task 6)
When I use setState(), it tells Flutter  that some data in my app 
has changed, like the counter number going up or resetting back to zero. 
Anything I change inside setState() makes Flutter rebuild that part of 
the screen, so I can see the new value right away. But if I change the 
variable without putting it inside setState(), the number still changes 
in the background, Flutter just has no idea it happened, so the screen 
stays exactly the same as before. That's basically why my app needs 
setState() — without it, my code and my screen would be out of sync.
